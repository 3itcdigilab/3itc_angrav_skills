# Antigravity Skills Collection

Koleksi terkurasi Agent Skills untuk Google Antigravity.

## Isi Koleksi
- **`impeccable`**: Spesialis desain UI/UX, tata letak, micro-interactions, responsive styling, typography, dan accessibility.
- **`ECC Skills (286 skills)`**: Framework performa & rekayasa agent dari [affaan-m/ECC](https://github.com/affaan-m/ECC) (TDD, Continuous Learning, Evaluasi Agent, Audit Kode, Arsitektur Backend & Frontend, Security, dll).

## Cara Pakai di Device Baru

Di laptop / komputer baru yang sudah terpasang Google Antigravity, jalankan satu perintah berikut di terminal:

### Windows (PowerShell)
```powershell
git clone <URL_REPO_INI> "$HOME\.gemini\config\skills"
```

### macOS / Linux (Terminal)
```bash
git clone <URL_REPO_INI> ~/.gemini/config/skills
```

Setelah di-clone, buka Antigravity dan seluruh skills otomatis langsung aktif di semua project!
